# 声压级分析节点设计方案

## 1. 背景与目标

项目需要新增两个工程声学分析节点：

1. 时变总声压级：计算随时间变化的滑动等效连续声压级或 Fast/Slow 指数时间计权声级。
2. 稳态频率声压级：计算完整音频记录的窄带或倍频程声压级曲线。

输入是普通归一化数字音频，用户提供统一的 `Pa/FS` 比例校准系数。两个节点输出绝对声压级 `dB SPL`，逐声道计算，并支持单个音频或批量音频。第一版定位为工程分析用途，不宣称 IEC/GB 仪器等级或标准合规。

本设计同时引入保留物理坐标的通用曲线数据契约，并打通曲线预览和 AI 一维特征输入流程。第一版保留完整曲线形状，不在声压级节点中提取均值、峰值、分位数等统计特征；这些统计量后续由独立节点承担。

## 2. 节点库位置

在“特征提取”中新增“声学分析”子分类，并放在现有 1D、2D 特征之前：

```text
特征提取
├─ 声学分析
│  ├─ 时变总声压级
│  └─ 稳态频率声压级
├─ 1D 特征
├─ 2D 特征
├─ AI 特征
└─ 特征后处理
   ├─ 特征向量化
   └─ 曲线转一维特征
```

声压级节点负责具有物理单位的分析计算；“曲线转一维特征”负责校验、对齐并转换为 AI 可消费的一维特征。

## 3. 端口和数据契约

### 3.1 声压级节点端口

两个声压级节点采用相同的端口结构：

- 输入：`音频`，类型 `AUDIO`，必需；支持 `AudioData` 或 `List[AudioData]`。
- 输出：`声压级曲线`，新增类型 `CURVE`；单文件输出 `CurveData`，批量输入输出 `List[CurveData]`。

不根据运行时声道数动态生成端口。所有声道通过一个输出端口传递，并在数据对象内部保持独立。

### 3.2 CurveData

新增通用曲线数据对象 `CurveData`，至少包含：

- `data`：实数数组，形状为 `(channels, points)`；
- `x`：显式横坐标，形状为 `(points,)`；
- `x_name`、`x_unit`：例如“时间”/`s`、“频率”/`Hz`；
- `y_name`、`y_unit`：本功能为“声压级”/`dB SPL`；
- `curve_type`：区分时变 Leq、指数时间计权、窄带和倍频程曲线；
- `channel_names`：例如 `Ch 1`、`Ch 2`；
- `source_file`：源音频路径；
- `metadata`：校准、计权、分析参数、有效范围和数据质量警告。

`CurveData` 与现有 `FeatureData` 并存，不改变旧数据结构、旧端口或旧工作流序列化。`CURVE` 默认不与 `FEATURE` 直接兼容，避免训练流程忽略物理坐标或误用不一致网格。

## 4. 公共计算参数

两个声压级节点共享以下参数：

| 参数 | 类型与默认值 | 说明 |
|---|---|---|
| 校准系数 | 浮点，必填、无默认值 | 单位 `Pa/FS`，必须大于 0；同一节点实例应用于批次内全部文件和声道 |
| 参考声压 | 浮点，默认 `20 μPa` | 高级参数，必须大于 0 |
| 频率计权 | 选择，默认 Z | Z、A、C |
| 去除直流 | 布尔，默认开启 | 在计权和声级计算前逐声道去除均值 |
| 声级下限 | 浮点，默认 `-200 dB` | 防止静音产生 `-∞` |
| 削波检测 | 布尔，默认开启 | 疑似削波只警告，不中止计算或修改样本 |

校准系数必须由用户显式填写。属性面板需要支持“必填但尚未设置”的浮点参数，以及适合很小或很大校准系数的精度或科学计数法显示。

两个节点共用同一套校准、Z/A/C 计权、声级转换和异常检测实现，避免相同输入得到不一致结果。

## 5. 时变总声压级节点

### 5.1 参数

| 参数 | 默认值 | 可见条件或说明 |
|---|---|---|
| 计算模式 | 滑动 Leq | 滑动 Leq、指数时间计权 |
| 积分时间 | `1.0 s` | 仅滑动 Leq |
| 输出步长 | `0.1 s` | 滑动 Leq 默认值 |
| 时间计权 | Fast | 仅指数模式；Fast `125 ms`、Slow `1 s` |
| 输出步长 | `0.05 s` | 指数模式默认值 |

滑动 Leq 仅输出完整窗口，横坐标取窗口中心。指数时间计权从零能量状态启动，并在元数据中记录启动瞬态范围。输出步长只对完整采样率下的指数响应结果抽取曲线点，不改变时间计权计算本身。

### 5.2 算法

对归一化数字波形 `x[n]` 使用 `Pa/FS` 校准系数 `K`：

```text
p[n] = x[n] × K
```

对校准后的压力波形去除直流并应用 Z/A/C 频率计权，得到 `p_w[n]`。滑动 Leq 为：

```text
Leq(t) = 10 log10(mean(p_w[n]^2) / p0^2)
```

实现时优先使用平方声压累计和计算重叠窗口，避免逐窗口重复求和。Fast/Slow 模式在平方声压上执行一阶指数平滑：

```text
q[n] = (1 - alpha) p_w[n]^2 + alpha q[n - 1]
alpha = exp(-1 / (sample_rate × tau))
L(t) = 10 log10(q[n] / p0^2)
```

其中 Fast 的 `tau=0.125 s`，Slow 的 `tau=1 s`。

## 6. 稳态频率声压级节点

节点始终分析每段输入音频的完整有效长度。如需排除启动、结束或其他非稳态片段，应在上游使用裁剪节点。

### 6.1 参数与联动

| 参数 | 默认值 | 可见条件或说明 |
|---|---|---|
| 分析类型 | 倍频程 | 窄带、倍频程 |
| 窄带估计方法 | Welch | 仅窄带；FFT、Welch |
| FFT 点数 | auto | FFT 模式；同一批输入时长已统一 |
| 窗函数 | Hann | FFT、Welch及倍频程内部谱估计 |
| Welch 分段长度 | 4096 | Welch及倍频程 |
| Welch 重叠率 | 50% | Welch及倍频程 |
| Welch 平均方式 | mean | Welch及倍频程 |
| 倍频程分数 | 1/3 | 仅倍频程；1/1、1/3、1/6、1/12 |
| 最低频率 | 20 Hz | 必须大于 0 |
| 最高频率 | 20000 Hz | 实际有效上限受 Nyquist 频率约束 |

切换模式时只隐藏非活动参数，不删除其值；切回后恢复原设置。工作流保存全部参数，但执行时只校验和使用活动参数组。依赖关系应由通用参数可见条件机制描述，不继续在属性面板中按节点类型硬编码。

### 6.2 窄带算法

FFT 使用完整记录的一次单边 periodogram；Welch 在完整记录内进行分段、加窗、重叠和线性功率平均。内部谱密度单位为 `Pa²/Hz`。

每个频率分辨带的均方声压由 `PSD × Δf` 得到，再转换为 `dB SPL`。不得将 `dB/Hz` 谱密度直接标记为声压级。输出横坐标是实际频率点。

### 6.3 倍频程算法

倍频程模式使用 Welch 功率谱密度作为工程分析基础。根据所选 `1/1、1/3、1/6、1/12` 生成中心频率及上下频带边界，并在线性能量域积分各频带 PSD。

频率栅格单元跨越频带边界时，按栅格单元与频带的重叠比例分配能量，不只依据频点中心是否落入频带。若当前 Welch 频率分辨率不足以可靠表示最低目标频带，节点应明确报错并提示所需最小分段长度，不静默输出零、NaN 或无效声级。

## 7. 数值安全与异常处理

内部计算统一使用 `float64`。取对数前不使用固定 `1e-10`，而是根据参考声压和用户设置的声级下限计算能量下限：

```text
minimum_energy = p0^2 × 10^(level_floor / 10)
safe_energy = max(energy, minimum_energy)
level = 10 log10(safe_energy / p0^2)
```

均方声压和谱积分理论上应非负，因此不使用 `abs()` 掩盖异常：

- 非有限能量直接报错；
- 明显负能量视为算法或数据异常并报错；
- 仅对浮点舍入导致的极小负值截断为零；
- 静音使用配置的声级下限；
- 空输入、无效采样率、无效校准值和非法频率范围明确报错。

疑似数字削波采用继续计算并警告的策略。检测结果精确到源文件和声道，并记录检测阈值、疑似削波样本数等元数据。节点不尝试修复削波数据。

## 8. 可视化

声压级计算节点的直接预览遵循现有 FFT 等特征节点的批量预览方式：

- 批量输出保持 `List[CurveData]`，每个音频对应一个条目；
- 条目选择器优先显示源音频文件名；
- 每次只预览当前条目的一个声道；
- 提供声道选择框，默认选择 `Ch 1`；
- 使用 `CurveData.x` 和轴单位显示真实物理坐标；
- 倍频程曲线默认使用对数频率轴。

增强现有“多曲线查看器”，不新增专用声压级查看器：

- 识别 `CurveData` 并直接使用显式物理坐标；
- 显示时间/频率和 `dB SPL` 轴名称及单位；
- 时变曲线默认线性时间轴；
- 窄带频率轴允许线性或对数显示；
- 倍频程默认对数频率轴并显示实际中心频率；
- `CurveData` 默认使用原始坐标，不归一化为长度百分比；
- 只有横坐标一致的曲线才能直接聚合；
- SPL 平均曲线采用线性能量平均，不直接算术平均 dB：

```text
L_avg = 10 log10(mean(10^(L_i / 10)))
```

普通音频、NumPy 数组和现有 `FeatureData` 继续使用原有查看逻辑，避免改变旧工作流行为。

## 9. AI 特征流程

新增“曲线转一维特征”节点：

- 输入：`CURVE`；
- 输出：`FEATURE_1D`；
- 保留完整曲线形状，不提取统计量；
- 单样本保持 `(channels, points)`；
- 批量训练数据保持 `(samples, channels, points)`，模型输入阶段转换为 `(samples, points, channels)`；
- 不把不同声道拆成独立样本，保持文件、标签和样本一一对应。

默认采用严格模式，校验：

- 声道数和点数；
- 横坐标数量及数值；
- 横纵轴单位；
- 曲线类型；
- Z/A/C 计权；
- Leq、Fast/Slow、FFT、Welch或倍频程模式；
- 倍频程分数；
- 参考声压和其他影响物理语义的配置。

任何物理语义或坐标不一致均明确报错，不提供“忽略差异并强制转换”。可选的固定网格重采样必须由用户显式启用：时变曲线可沿时间轴插值，窄带曲线可沿频率轴插值；不同倍频程分数之间禁止普通插值，应回到原始音频重新计算。

同一批训练音频已在上游统一采样率和时长，因此第一版默认严格转换即可稳定生成相同形状。转换节点不进行幅值归一化，避免破坏绝对 SPL 信息。

## 10. 工作流使用约束

- 普通数字音频文件加载为浮点波形不等于改变物理标度；`Pa/FS` 用于恢复绝对压力。
- 上游峰值归一化会破坏原始绝对声级关系，应在节点说明和文档中明确警告。
- 数字增益增强可以表示合成声级变化，但用户必须有意识地使用并避免削波。
- 不允许把不同校准、计权或分析配置的曲线无提示混入同一训练批次。
- 第一版不支持每文件或每声道独立校准；不同校准批次应使用不同节点实例或分开运行工作流。

## 11. 测试与验收

至少覆盖以下测试：

- 已知 RMS 正弦波得到预期 `dB SPL`；
- 输入幅值或校准系数加倍时声级增加约 `6.02 dB`；
- 多声道独立计算且声道顺序不变；
- 滑动 Leq 对稳态输入保持恒定；
- Fast/Slow 对阶跃输入表现出正确的相对响应速度；
- FFT/Welch 频带能量与相同计权下的时域总能量在合理容差内一致；
- 单频信号峰值落在正确的窄带频点或倍频程；
- `1/1、1/3、1/6、1/12` 的中心频率和边界正确；
- 频率分辨率不足时给出可操作的错误信息；
- A/C/Z 在两个节点间产生一致计权语义；
- 静音输出配置的声级下限，不产生 `NaN` 或 `-∞`；
- 无效校准值、无效采样率和非有限输入被拒绝；
- 疑似削波继续计算并产生文件、声道级警告；
- 参数模式切换正确隐藏控件并保留非活动参数值；
- `CurveData` 在多曲线查看器中使用正确坐标、单位和能量平均；
- `CurveData → FEATURE_1D → AI` 保持完整曲线及稳定形状；
- 旧 `FeatureData`、旧节点和已有工作流继续正常加载和显示。

## 12. 非目标

第一版不包含：

- IEC/GB 仪器等级或标准合规声明；
- 每文件、每声道动态校准端口；
- 麦克风灵敏度、前置放大器增益和 ADC 电压的完整测量链建模；
- 声道波形平均或默认声级合成；
- 从曲线提取均值、峰值、分位数等固定长度统计特征；
- 不同倍频程分数之间的插值转换；
- 削波波形修复。
