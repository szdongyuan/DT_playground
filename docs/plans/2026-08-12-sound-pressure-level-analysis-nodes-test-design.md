# 声压级分析节点测试设计

## 1. 测试对象

- `CurveData` 数据契约和 `CURVE` 端口兼容性；
- Pa/FS 校准、声级下限、Z/A/C 计权和削波告警；
- 滑动 Leq、Fast/Slow 时间计权；
- FFT、Welch和 1/1 至 1/12 倍频程声压级；
- 曲线转一维特征的严格校验和固定网格转换；
- 参数可见条件、多曲线物理坐标及 SPL 能量平均；
- 节点注册、排序、序列化和旧功能兼容。

## 2. 等价类与边界

| 类别 | 代表输入 | 预期 |
|---|---|---|
| 有效校准 | 正有限 `Pa/FS` | 成功 |
| 无效校准 | None、0、负数、NaN | 拒绝 |
| 声音 | 已知 RMS 正弦、常量、双声道 | 预期 SPL 且声道独立 |
| 静音 | 全零 | 输出声级下限，无 NaN/-∞ |
| 削波 | 连续满量程样本 | 继续计算并告警 |
| Leq 窗口 | 恰好一窗、短于一窗、多重叠窗 | 正确点数或明确失败 |
| 指数计权 | 阶跃输入 | Fast 响应快于 Slow |
| 频谱 | bin 对齐单频、宽带输入 | 峰值位置和能量正确 |
| 倍频程 | 1/1、1/3、1/6、1/12 | 中心频率递增且峰值频带正确 |
| 分辨率 | 足够/不足 | 成功或可操作错误 |
| 曲线批次 | 元数据与坐标一致/不一致 | 转换成功或严格拒绝 |
| 可视化 | 普通 FeatureData / SPL CurveData | 保持旧语义 / 使用物理语义 |

## 3. 场景测试

1. 幅值或校准系数加倍，Z 计权声级增加约 6.02 dB。
2. 同一稳态信号的时域 Leq 与窄带频带能量和在容差内一致。
3. A/C/Z 计权均产生有限输出，且同一计权在两个节点中复用同一预处理路径。
4. 节点模式切换只改变控件可见性，不清除非活动参数值。
5. CurveData 进入多曲线查看器后保留显式坐标、dB SPL 纵轴和对数频率标记。
6. SPL 聚合使用线性能量平均，普通数组仍使用算术平均。
7. 严格曲线转换保留 `(channels, points)`；不一致坐标、单位、计权或模式明确失败。
8. 已有 FeatureData、节点目录和工作流序列化行为不回归。
9. 直接预览批量曲线时按音频分页，显示源文件名，并默认显示当前音频的 `Ch 1`。

## 4. 依赖策略

- 使用 NumPy 生成确定性合成音频，不读取真实音频文件；
- 直接使用 SciPy 信号实现，不 mock 数值库；
- Qt 属性面板使用现有 offscreen `QApplication` 测试模式；
- 不访问网络、数据库或音频设备。
